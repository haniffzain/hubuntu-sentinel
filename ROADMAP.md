# Hubuntu Sentinel — Public Roadmap

This roadmap shows product direction without exposing private implementation details.

## Phase 1 — Visibility

- Network connection monitoring
- IP classification
- Application/process attribution
- Compact user interface

**Status:** in active development

## Phase 2 — Memory and Analysis

- SQLite event history
- Baseline learning
- Explainable risk scoring
- Incident correlation

**Status:** in active development

## Phase 3 — Protection Logic

- Normal / Strict / Aggressive protection profiles
- Policy-driven decisions
- Response planning
- safer automated protection behaviour
- clearer user-facing explanations

**Status:** in active development

## Phase 4 — Product Hardening

- diagnostics and health monitoring
- log retention controls
- update verification
- signed releases
- rollback strategy
- tamper-resistance improvements
- performance testing

**Status:** planned

## Phase 5 — Stable Release

- installation package
- stable documentation
- release notes
- supported upgrade path
- public binary release decision
- source publication decision

**Status:** future milestone

## Longer-term direction

After the local endpoint experience is stable, future work may include optional enterprise capabilities such as central visibility, fleet policy, SIEM integration and role-based administration.

The primary console will remain simple-first so everyday users are not forced to understand security jargon.
